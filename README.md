# NoctaVox Addons

The following repository contains a singular NoctaVox addon, but more to come! 

#### Installation
To install addons, download or build the desired binaries, and store them in
the `$CONFIG/noctavox/addons/` folder. Certain addons will require flags to be
set in the `config.toml` file. 

## Transpose

> **Import and Export your Playlists!**

 - Interactive mode 
 - Supports m3u/8, json, and csv format
 - Works as a standalone program! (Run nv-tranpose if installed)
